# الحسامي نيوز

واجهة Next.js عربية RTL جاهزة للرفع إلى GitHub ثم النشر على Vercel.

## التشغيل

```bash
npm install
npm run build
npm start
```

## Vercel

اربط مستودع GitHub بهذا المشروع. لا توجد حاجة إلى إعداد Build Command خاص؛ Vercel سيكتشف Next.js تلقائياً.

بعد إنشاء المشروع أضف متغيرات البيئة من `.env.example` عند ربط Supabase.

> هذه النسخة هي واجهة البداية فقط. الربط الفعلي بالمصادقة، Supabase، التخزين، الذكاء الاصطناعي والإشراف الآلي يتم في المرحلة التالية.
