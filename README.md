# الحسامي نيوز

مشروع Next.js App Router عربي RTL، مجهز للنشر على Vercel عبر GitHub.

## النشر
- ارفع محتويات هذا المجلد إلى جذر مستودع GitHub.
- في Vercel اختر المستودع واترك Framework = Next.js.
- لا توجد متغيرات بيئة مطلوبة للواجهة التجريبية الحالية.

## ملاحظة
هذه النسخة تستخدم Next.js 15.5.26، وهو إصدار Maintenance LTS منشور من Next.js بتاريخ 22 سبتمبر 2026 لمعالجة مشكلة أمنية حرجة. راجع وثائق Next.js الرسمية قبل أي ترقية مستقبلية.
